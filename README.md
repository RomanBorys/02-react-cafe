# 02-react-cafe

React + TypeScript feedback widget for Sip Happens Café.

## Run

```bash
npm install
npm run dev
```

## Check

```bash
npm run typecheck
npm run build
```

## Features

- Good / Neutral / Bad voting
- Total vote count
- Positive feedback percentage
- Conditional VoteStats / Notification rendering
- Conditional Reset button
- TypeScript interfaces and union types
- CSS Modules
- modern-normalize
